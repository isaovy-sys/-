# 戦国出世録 ― 足軽から天下人へ

太閤立志伝のような、戦国時代の立身出世シミュレーション（個人用）。

## 遊び方
`index.html` をブラウザ（Chrome / Safari / Edge）で開くだけ。インストール不要。
スマホでも遊べます。セーブは「屋敷」から（そのブラウザに保存）。

## 内容
- 1554年、清洲の足軽から1582年「本能寺の変」までの物語
- 評定で任務を受ける：普請・兵糧調達・偵察・野盗討伐・商人との交渉・調略
- 勲功がたまると昇進：足軽 → 組頭 → 足軽大将 → 侍大将 → 部将 → 城主 → 宿老
- 道場・寺で修行（剣術・弓術・鉄砲・馬術・弁舌・算術・忍術など）
- 茶屋で人と縁を結ぶ：前田利家、ねね（結婚）、蜂須賀小六・竹中半兵衛（与力）など
- カード式の一騎討ち・論戦、普請ミニゲーム、合戦
- 歴史イベント：桶狭間、墨俣一夜城、稲葉山、金ヶ崎、姉川、長篠、山崎 など

## ファイル
- `index.html` … 画面
- `style.css` … 見た目
- `js/data.js` … 町・人物・品物などのデータ（数値をいじって調整可能）
- `js/game.js` … ゲーム本体
